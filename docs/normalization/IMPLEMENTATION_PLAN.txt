Phase 1: Correctness Fixes (Incremental, Each Behind Tests)
1.1 Unicode Normalization & Offset Mapping
File: src/riskforge/normalization/gazetteer.py
Change: Add _preprocess(text: str) -> tuple[str, list[int]] returning:
- clean_text: unicodedata.normalize('NFC', text) with whitespace normalized (\s+ → single space)
- orig_idx_map: List where orig_idx_map[i] = original_index for each character in clean_text
Invariant: For every returned span:
raw_narrative[span.start_char:span.end_char] == span.text
Implementation: Match on clean_text, get (clean_start, clean_end), map to original:
- orig_start = orig_idx_map[clean_start]
- orig_end = orig_idx_map[clean_end - 1] + 1 (since end is exclusive)
- Extract span.text = raw_narrative[orig_start:orig_end]
Note: NFC can expand or contract (e.g., é as U+00E9 vs U+0065 U+0301). Mapping handles both.
Tests (add to regression suite):
- café (NFC vs NFD) → spans map to original NFC indices
- hello\t\nworld → spans skip collapsed whitespace correctly
- Mixed: café\tworld → both normalizations compose
1.2 Word Boundary Replacement (Conservative)
File: src/riskforge/normalization/gazetteer.py
Current: \b(?:token1\s+token2\s+...)\b — matches BOP's, BOP., (BOP) because \b treats punctuation as boundary
Proposed: Replace \b with custom boundary assertion that excludes possessives and trailing punctuation:
# Word char = Unicode letter/number/underscore (matches \w with re.UNICODE)
# Boundary = NOT preceded/followed by word char
START_BOUNDARY = r'(?<![^\W_])'  # Not preceded by word char (allows start, space, punctuation)
END_BOUNDARY   = r'(?![^\W_])'   # Not followed by word char
Effect on Current Behavior:
Input	Current (with \b)	Proposed (with custom)
BOP	✅ Match	✅ Match
BOP's	✅ Match	❌ No match (followed by 's - word chars)
BOP.	✅ Match	❌ No match (followed by .)
(BOP)	✅ Match	❌ No match (preceded by (, followed by ))
BOP,	✅ Match	❌ No match
BOP;	✅ Match	❌ No match
⚠️ UNRESOLVED DOMAIN DECISION: Whether possessives/trailing punctuation should match. Current behavior matches them. Proposed change rejects them. Decision required before implementation.
